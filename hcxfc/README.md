# 校服之家

校服自由零售平台 - 商家自助开店，每家店铺独立经营（不做跨店铺的"按学校汇总所有商家"列表，避免同校商家互相比价压价），家长通过店铺专属链接进店浏览，直接联系商家交易（不含在线支付）。

## 技术栈
Node.js + Express + better-sqlite3(WAL) + JWT + bcryptjs + multer/sharp，单表数据库，跟简铺是同一套架构思路，部署方式也一样（宝塔 + PM2）。

## 部署步骤（参考简铺的部署方式）

1. 把整个项目文件夹上传到服务器，比如 `/www/wwwroot/hcxfc/`
2. 进入目录安装依赖：
   ```bash
   cd /www/wwwroot/hcxfc
   npm install --production
   ```
3. （可选）设置环境变量，不设就用默认值：
   - `PORT`：监听端口，默认 4100
   - `JWT_SECRET`：登录token加密密钥，**生产环境务必自己设一个随机字符串**，不要用默认的
   - `ADMIN_PHONE` / `ADMIN_PASSWORD`：首次启动创建管理员账号用，不设的话手机号默认 `13800000000`，密码会随机生成并打印在启动日志里
4. 用 PM2 启动（服务名建议叫 `hcxfc`）：
   ```bash
   pm2 start server.js --name hcxfc
   pm2 logs hcxfc --lines 20
   ```
   **第一次启动一定要看一眼日志**，把打印出来的管理员手机号和密码记下来，登录总后台 `/admin.html` 就是用这个账号。
5. 在宝塔里把这个端口反向代理到你准备好的二级域名上，配好SSL证书就行，跟简铺的站点配置方式一样。

## 目录结构

```
hcxfc/
├── server.js              # 主程序
├── hcxfc.db                # SQLite数据库（启动后自动生成）
├── package.json
└── public/
    ├── index.html          # 首页：进来直接是注册开店表单（不设单独的品牌介绍页）
    ├── shop.html            # 店铺主页（店招+简介+地址+联系方式+按学校分类的商品）
    ├── product.html        # 商品详情（四张主图+联系商家）
    ├── merchant_login.html # 商家登录（也可以从这里切换到注册）
    ├── merchant_admin.html # 商家后台（店铺装修+商品管理+试用/订阅状态提示+注销）
    ├── admin.html           # 总后台（商家管理+试用/订阅操作+数据概览）
    └── uploads/             # 商品图片存储目录
```

## 配色方案

主色（强调色）：燃橙棕色 `#c1592f`，深色态 `#9e4524`，浅底色块 `#f3e3d6`。
背景：暖奶油色 `#f8f1e6`。
辅助色：藏青色 `#27415f`（用在首页头图、店铺店招默认底色等）。

## 功能范围（当前版本）

- 首页 `/` 直接是"免费注册开店"表单，填手机号+店铺名+密码即可开店，不需要先看一个品牌介绍页
- 商家手机号注册/登录，自助开店，装修店铺：店招（头图）、店铺名称、简介、地址、微信号、联系电话
- 商家管理商品：所属学校（店内分类，比如"XX中学"）、季节（冬季款/夏季款二选一）、名称、价格、可选尺码（标签形式，不分尺码库存）、**固定最多4张主图**（类似简铺详情页风格，自动压缩成WebP）、说明文字
- 前台：每家店铺有自己独立的链接 `/shop.html?shop={店铺码}`，进店后按学校分类浏览 → 商品详情（四图轮播）→ 点击"微信联系/电话联系"弹出商家联系方式
- **刻意不做**"全平台按学校汇总所有商家商品"的聚合页面——这是按你的要求特意去掉的，避免同一所学校下多个商家的商品被摆在一起比价，导致价格战、没利润
- **试用/订阅状态机**（新增）：
  1. 商家注册后自动进入**免费搭建期（3天）**，店铺正常对外可见，可以随意装修、上传商品
  2. 商家私下转账20元给你之后，你在总后台点"标记已付20元开通试用"，进入**付费试用期（14天）**
  3. 付费试用到期后，你可以在总后台点"正式开通"并输入天数（比如365天），商家进入**已开通**状态；也可以商家自己在后台点"注销店铺"主动退出
  4. 任何一个阶段到期且没有续下一步操作，店铺会**自动下线**（家长访问显示"该店铺已下线"），但**数据会保留30天**，这30天内你随时可以在总后台重新标记付费/开通把店铺救活；超过30天，总后台会出现"清理过期数据"按钮，点了才会真的删除这个商家的数据
  5. **手机号最多注册2次**：即使店铺被注销或清理，这个手机号的注册次数依然会被记住（单独一张表，不随商家数据删除），用完2次之后这个手机号就不能再注册新店铺了
  6. 20元的收款目前是**线下方式**（商家微信/转账给你本人），系统里没有在线支付入口，你收到钱后手动在总后台点一下"标记已付20元开通试用"即可——这跟简铺一贯不做在线支付的做法是一致的，如果后面想做在线收款，需要单独接入支付渠道，再告诉我
- 总后台：查看所有商家、封禁/解封、查看每个商家的试用/订阅状态、标记付费试用/正式开通/清理过期数据、平台数据概览（商家数/商品数/覆盖学校数）——这个是平台方自己看的，不对外展示
- **不含**：在线支付、下单流程、尺码库存——这些目前按你的要求先不做，后续要加随时说

## 商家怎么把店铺分享出去

每个商家登录后台后，右上角"预览店铺"链接就是他们自己的专属店铺地址（`/shop.html?shop=店铺码`），商家自己转发到微信群/朋友圈/家长群即可，这个链接平台不会主动在任何地方汇总展示。

## 日常运维（跟简铺习惯一致）

```bash
pm2 status                     # 查看服务状态
pm2 restart hcxfc              # 改完server.js后重启
pm2 logs hcxfc --lines 50      # 查看日志
cp hcxfc.db hcxfc.db.bak_$(date +%Y%m%d)   # 手动备份数据库
```

public/ 下的页面文件修改后不用重启服务，刷新浏览器就生效；改 server.js 必须 `pm2 restart hcxfc`。
